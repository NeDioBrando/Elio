# Elio — Liquid Glass, палитры и динамический логотип

## Что сделано

- **Дизайн Liquid Glass** для десктопного приложения, popup расширения и общих компонентов: плавающие стеклянные панели (`backdrop-filter` + насыщенность), блики и тонкие светлые кромки, мягкие тени, живой фон из размытых цветных пятен, стеклянные кнопки, карточки, композер чата, пузыри, карточки инструментов, терминал.
- **10 палитр**, у каждой есть светлый и тёмный вариант: `aurora` (по умолчанию), `ocean`, `amethyst`, `orchid`, `sakura`, `ember`, `crimson`, `emerald`, `graphite` и `linen` (прежний тёплый «лён»). Светлая/тёмная тема переключается отдельно, как и раньше.
- **Логотип меняется вместе с палитрой.** Он нарисован средствами CSS (маска-буква «e» + точка поверх градиента палитры), поэтому перекрашивается мгновенно, без картинок. Используется в боковой панели, приветствии, popup и меню оверлея.
- Выбор палитры: Настройки → «Color palette», кнопка-капля в заголовке окна и в popup расширения. Выбор синхронизируется между приложением и расширением (настройка `rsPalette`).
- Контраст текста проверен автоматически по реальному фону для всех 10 палитр × 2 тем на основных экранах (WCAG AA, 4.5:1).
- Для `prefers-reduced-motion` анимация фона отключена, для `prefers-reduced-transparency` и браузеров без `backdrop-filter` стекло заменяется плотной заливкой.

## Как добавить свою палитру

Все палитры описаны в `tools/gen_palettes.py` (id, название, базовые цвета). Скрипт сам считает светлый и тёмный наборы токенов `--elio-*`, цвета пятен фона, градиент логотипа, проверяет контраст и подбирает акцент.

```
python tools/gen_palettes.py     # перегенерирует блок PALETTES в core/theme.css
python tools/stamp_build.py      # обновит core/build-info.json
```

Скрипт сам копирует `core/theme.css` в `elio-Extension/core/`. После добавления палитры добавьте её id в список допустимых значений `rsPalette` в `agent/src/preferences.rs` (проверка `matches!`) и в `PALETTES` в `core/theme.js`.

## Где что лежит

| Файл | Назначение |
| --- | --- |
| `core/theme.css` | токены палитр, стеклянные токены, логотип, пикер палитры, стили popup |
| `core/theme.js` | `elioTheme.applyPalette / mountPaletteBrowser / palettes`, хранение выбора |
| `desktop/elio.css` | стеклянная оболочка десктопа (раздел «Liquid Glass») |
| `agent/src/desktop.html` | разметка: логотип, карточка «Color palette», кнопка в заголовке |
| `agent/src/preferences.rs` | сохранение и проверка `rsPalette` |
| `popup.html`, `popup.js` | палитра и логотип в popup расширения |
| `tools/gen_palettes.py` | генератор палитр |

Корневые файлы (`core/`, `popup.*`, `background.js`) зеркалируются в `elio-Extension/` — после правок копируйте их туда (тесты проверяют идентичность).

## Ограничения

- Значок самого `.exe`, ярлыка и трея остаётся статичным `.ico` — Windows не позволяет менять его в рантайме без перекомпиляции ресурсов. Динамический логотип работает внутри приложения и расширения.
- Оверлей на сайтах ИИ намеренно не перекрашивается (правило «не перекрашивать страницы провайдеров»).
- Rust-часть (`preferences.rs`, поле палитры и тест) написана без локальной компиляции — проверит `cargo test` в GitHub Actions.
