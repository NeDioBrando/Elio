# elio v1

Независимый модифицированный форк Elio 1.24.20 для Windows 10 x64 и Chrome/Chromium. Предок проекта — ZeroScript-Free. Лицензия GPL-3.0-or-later; исходные авторские и сторонние уведомления сохранены. Это не официальный релиз Elio.

## Что готово

- Имя приложения и будущего EXE: `elio`, `elio.exe`.
- Новая синяя палитра по умолчанию и собственный значок.
- Показываемая версия **v1**. Техническая версия Chromium/Cargo — **1.0.0**: эти форматы не принимают строку `v1`.
- Перенесён Vani-провайдер из предоставленного тестового расширения. Добавлены HTTPS `vani.ai`, `www.vani.ai`, `c.vani.ai`; сам чат открывается на **https://c.vani.ai/c**. На главной странице сайта без чата выполнить команды нельзя.
- Код обновлятора приложения удалён: нет фоновой/ручной проверки, загрузки/установки релизов, update API, страницы обновлений и синхронизации release-status в расширении.
- Убраны рекламные/донатные предложения прежнего издателя, чтобы они не выдавались за поддержку elio.
- Остальные провайдеры и инструменты сохранены. Установка внешних MCP-зависимостей не является обновлением elio и остаётся доступной.

## Важно: состав этой поставки

**Этот исходный архив не содержит готового Windows EXE.** В нём исходники, готовое распаковываемое расширение, тесты и воспроизводимый сценарий сборки EXE. Не подставляйте вместо него прежний elio.exe: в старом бинарнике останется обновлятор!

Linux-проверка Rust и тесты не доказывают работоспособность Windows GUI. После сборки необходима проверка на вашем Windows 10 с Roblox Studio. См. TEST-REPORT.md.

## Вариант A — получить EXE через GitHub Actions

Локально устанавливать Rust/Visual Studio в этом варианте не нужно.

1. Создайте собственный пустой GitHub-репозиторий. Учитывайте условия бесплатного/платного запуска Actions для своего аккаунта.
2. Загрузите **содержимое** папки исходников в корень репозитория, включая скрытую папку `.github`. Файлы `agent/Cargo.toml` и `.github/workflows/build-windows.yml` должны лежать именно по этим путям. Не загружайте ZIP одним файлом.
3. Откройте **Actions → Build elio v1 (Windows x64) → Run workflow**.
4. Только после зелёного завершения скачайте artifact `elio-v1-Windows-x64`. Внутри будет `elio-v1-Windows-x64.zip` с новым EXE, DLL и расширением.
5. Если сборка красная, сохраните лог неудачного шага. Готовым считается только успешно собранный архив; workflow в этой среде не запускался.

Если используете Git в терминале (адрес репозитория подставьте свой):

```powershell
git init -b main
git add .
git commit -m "elio v1"
git remote add origin <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
git push -u origin main
```

Публикация и запуск Actions не выполнялись автоматически от вашего имени. При распространении EXE предоставляйте получателям соответствующий исходный код и лицензионные уведомления в соответствии с GPL.

## Вариант B — собрать локально на Windows 10 x64

Понадобятся:

- Visual Studio 2022 Build Tools: **Desktop development with C++**, MSVC x64/x86 и Windows 10/11 SDK с `rc.exe`.
- Rust **1.99.1**, target `x86_64-pc-windows-msvc` (GNU toolchain для этого build.rs не подходит).
- Python 3.13 и Node.js 24, доступные как `python`, `node`, `cargo` в терминале.
- Интернет для первоначального получения Cargo-зависимостей.

В PowerShell из папки исходников:

```powershell
rustup toolchain install 1.99.1 --profile minimal
rustup override set 1.99.1
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Windows.ps1
```

Сценарий запускает аудит форка, библиотечные тесты безопасности, `cargo build --release --locked`, затем проверяет `elio.exe --version` и формирует:

```text
dist\elio-v1-Windows-x64.zip
```

В EXE будут встроены новое имя, версия и ICO. Рядом упаковывается неизменённый Microsoft `WebView2Loader.dll` из upstream Windows-релиза; см. WINDOWS-RUNTIME-NOTICE.txt / windows-runtime/NOTICE.txt. Сам WebView2 Runtime должен быть установлен из официального источника Microsoft. Ничего не отключайте в защите Windows; неподписанный EXE может вызывать предупреждение о неизвестном издателе.

## Установка готовой Windows-сборки

1. Полностью закройте старый Elio и его обновлятор, если они запущены. Не кладите elio в старую папку Elio: внешний старый обновлятор способен перезаписать её независимо от нового кода.
2. Распакуйте ZIP в отдельную папку, например `C:\elio`. Не запускайте EXE прямо из ZIP.
3. Отключите старое расширение Elio, чтобы два расширения не добавляли две панели на один сайт.
4. В Chrome откройте `chrome://extensions`, включите **Режим разработчика → Загрузить распакованное расширение** и выберите `elio-Extension`. В Edge/Brave/другом Chromium используйте его страницу расширений. Тестировался Chromium; каждый другой браузер отдельно не проверялся.
5. Запустите `elio.exe`, откройте Roblox Studio и подключите Studio привычным для исходного проекта способом. Настройка стороннего MCP-рантайма может потребовать Python/Node и разрешений на первоначальную установку зависимостей.
6. Откройте `https://c.vani.ai/c`, перезагрузите вкладку и нажмите Start Agent в панели elio.

Расширение загружается распакованным; в manifest нет `update_url`. Встроенного пути обновления самого elio нет. Общие обновления Chrome, Roblox Studio, WebView2 и внешних инструментов этот форк не отключает.

## Проверка после Windows-сборки

- Заголовок/панель показывают `elio v1`; кнопки и раздела обновлений нет.
- Через 10 минут простоя и повторный запуск папка/версия не меняются.
- На Vani видна одна панель; Start Agent получает список команд.
- Сначала выполните только чтение, например запрос имени открытого place или доступных сервисов; затем при необходимости проверьте изменение на отдельном тестовом place.
- Stop останавливает цикл; другое поддерживаемое AI-приложение по-прежнему подключается.
- Не запускайте Elio параллельно: используется тот же локальный порт моста `127.0.0.1:3000`. Новая айдентика не означает автоматическую совместную работу двух мостов на одном порту.

У elio отдельные имена путей/ключей приложения. Автоматическая миграция старой памяти, настроек и секретов не добавлялась; при необходимости используйте штатный экспорт/импорт, не копируйте токены в переписку.

## Ограничения проверки Vani

В живом анонимном чате проверены поиск поля ввода, одна отправка, подтверждение отправки, распознавание пользовательского/AI-сообщения и чтение завершённого ответа. Передача изображений, авторизованные аккаунты, исчерпание квоты, все модели, продолжительные диалоги и выполнение команд в Windows Roblox Studio здесь не проверялись. Если сайт меняет DOM, адаптер может потребовать корректировки. При неопределённом результате отправки адаптер не отправляет сообщение повторно сам.
