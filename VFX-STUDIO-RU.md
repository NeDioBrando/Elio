# VFX Studio в Elio 1.0.1

## Что добавлено
Встроенный скилл **VFX Studio** виден в Skills при обычном уровне усилий. Он подбирается для Roblox VFX-задач (частицы, искры, дым, ауры, взрывы, beams/trails/flipbooks) и прямого запроса использовать VFX Studio. Доступность Blender не мешает его выбору. Явный запрет пользователя учитывается; удалённая карточка не восстанавливается миграцией. Eclipse Animator остаётся отдельным встроенным скиллом для анимации персонажей.

Основной путь — сначала использовать подходящие материалы/пресеты установленного плагина, затем проверить вставленный результат и работать с принадлежащей задаче копией. Не пересоздавать всё с нуля и не выдавать поиск в Creator Store за поиск в библиотеке плагина.

Скилл читается через существующий `elio_skills` с id `builtin-vfx-studio`; ресурсы выдаются порциями с `next_offset`. Новых инструментов с выдуманными API плагина не добавлено. Ресурсы входят и в исходники, и в упаковываемую папку расширения.

## Что полезно помимо библиотеки
- Визуальный предпросмотр и ограниченная по времени проверка emission.
- Настройка flipbooks и проверка фактического поведения.
- Сохранение и повторное открытие своих пресетов там, где это поддерживает установленная версия.
- Проверка экспорта, attachments, текстур, мешей и последующее безопасное повторное использование.

Обычные свойства Roblox агенту чаще быстрее менять через существующие инструменты, чем двигать ползунки мышкой. Неизвестные панели, кривые и сгенерированные модули сначала изучаются на фактическом экспорте, а не исполняются на доверии.

## Важная граница автоматизации
Это **встроенный рабочий скилл, не прямой коннектор к закрытой библиотеке**. Для работы с интерфейсом нужны реально доступные и разрешённые средства управления рабочим столом на компьютере пользователя. Игровой mouse input не управляет панелью плагинов Studio.

Если управления интерфейсом нет, Elio должен использовать уже экспортированный эффект либо попросить вставить/выбрать нужный пресет. `motion_scan` не открывает внутреннюю библиотеку: он видит только реальные объекты DataModel. Скилл не устанавливает плагин, не покупает его и не публикует ассеты самостоятельно.

## Инспектор
`scripts/inspect_asset.luau` выполняет только чтение экспортированных объектов. Перед ним передаётся локальный SPEC с 1–8 точными путями либо явным `use_selection=true`.

Он выдаёт:
- корень и ограниченный список экземпляров;
- ссылки на текстуры, меши, звуки, SurfaceAppearance;
- наличие Script/LocalScript/ModuleScript без чтения или исполнения Source;
- отсутствующие/внешние/неоднозначные attachments;
- признак неполного результата при достижении лимитов.

Лимит — до 400 посещённых объектов, 128 уникальных asset-ссылок и 48 000 байт ответа. Признак `copy_candidate` не подтверждает лицензию, разрешение или внешний вид. Полная проверка источника/отпечатка и копирование делаются существующими motion-инструментами. В VFX-копировании используется точный `source_path`, не `asset_id`.

## Источники и права
Точный плагин: https://create.roblox.com/store/asset/135581141962270/VFX-Studio

Ссылки и ограничения исследования: `starter-skills/vfx-studio/references/sources.md`. В найденной сторонней документации есть примеры, прямо помеченные как AI-generated demonstration. Они не использованы как настоящий API. Отдельный GitHub-каталог текстур имеет ограничительные условия; его связь с конкретной установленной библиотекой не доказана. Нельзя переносить ни его API, ни его условия автоматически на все ассеты плагина.

Ни плагин, ни каталог, ни текстуры/меши/звуки третьих лиц в Elio не включены. Проверять нужно права конкретно выбранных материалов.

## Что проверено и что остаётся
Результаты автоматических проверок — `VFX-STUDIO-TEST-RESULTS.json`. Проверяются Rust-регистрация/миграция/маршрутизация, настоящее Skills UI в jsdom, чтение ресурсов через собранный агент и реальный Luau-код инспектора на симулированном DataModel.

На пользовательском ПК ещё нужно проверить установленную версию VFX Studio: открытие библиотеки, выбор и вставку пресета, его права, внешний вид и очистку предпросмотра. Здесь не было подключённой Studio; эти проверки не выдаются за пройденные.

## Сборка
Полный исходный архив предназначен для прежнего GitHub Actions workflow. Версия остаётся 1.0.1. Нового способа сборки не введено: в существующий Build-Windows.ps1 добавлены только тесты VFX. Oriveo, Figma, project memory и Eclipse сохранены.
