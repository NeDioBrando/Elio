# Elio — архитектура и миграция 1.0.1

## Интерфейс

Собственный бренд и иконка владельца; Claude использован как направление — бумажный фон, спокойная типографика, минимум украшений, а не как копируемая идентичность. Без загрузки внешних шрифтов/ресурсов при старте. Иконка встроена в native UI; PNG/ICO заменены в ресурсах приложения и расширения.

`desktop/elio.css` — единая оболочка; `desktop/chat.css` и `desktop/chat.js` — новый диалог. Все прежние рабочие разделы и функциональные ID сохранены. Главная теперь компактный стол подключения вместо двух больших рекламных панелей. Доступны мягкая льняная светлая и тёплая угольная тёмная темы; прежние настройки неоновых палитр сохранены в хранилище для совместимости, но не переопределяют Elio.

`overlay.css` изменяет только собственные элементы расширения. Не следует переносить бежевый фон на ChatGPT/Claude/другие сайты. Popup стал компактным: настройки и старые pairing-функции раскрываются при необходимости.

## Сообщения и инструменты

`core/chat-view.js` — отдельная презентационная модель, без исполнения кода. Распознаёт MCP/LUA-маркеры, command/tool JSON, служебные инструкции и feedback. Обычный текст, JSON без команды, код и пояснения до/после инструмента сохраняются. Технический текст доступен в раскрываемых деталях.

Карточка с часами = идёт выполнение; зелёная галочка = получена завершённая фаза или сопоставлен фактический результат; красная = ошибка; «запрошено» = нет подтверждения. Наличие команды само по себе не доказывает успешное выполнение. Пользовательские тексты не скрываются по одному упоминанию инструмента.

Рендер использует DOM/textContent, не HTML от ИИ. Поддерживаются кодовые блоки, простое жирное начертание и inline code. Это не полный Markdown-движок: таблицы/математика/прочие конструкции могут отображаться как текст.

## Исправления логики

- `task-send` передаёт `isUserPrompt=true`: явный запрос человека не должен маскироваться как автоматический служебный feedback.
- ACK возвращается после завершения provider submit, а не заранее. Ожидание ограничено: native 100 секунд, UI 105 секунд. Успешный ACK подтверждает submit, не будущий ответ модели.
- Локальный пузырь появляется сразу. При ошибке черновик остаётся; нет автоматической повторной отправки. Повтор того же текста использует тот же request ID. Неопределённый исход сохраняется в дедупликации — сначала проверьте браузер, затем меняйте/повторяйте запрос осознанно.
- `chat-read` принудительно перечитывает текущие элементы провайдера, не ждёт видимости вкладки/observer-кэша. Экспорт исключает подписи внедрённых карточек, сохраняя оригинал.
- Browser/tab/chat identity проверяется на пути доставки; закрепление вкладки сохранено. Когда фокус в Elio, расширение удерживает последнюю корректную вкладку, а не произвольный другой чат.
- После Stop новое явное сообщение сбрасывает stop/userStopped; остановка и ожидание внешних инструментов не считаются готовностью. Реальный provider generating и pending submit входят в busy.
- Start идёт по подтверждаемому маршруту. Пока браузер действительно подключается, интерфейс не должен выдавать старт за завершённую инициализацию.

Это исправления найденных дефектов исходников, проверенные unit/mock-интеграционными тестами. Они не означают, что протестированы все сайты, аккаунты и состояния виртуализации DOM. История ограничена тем, что загрузил сайт и захватило расширение; она не является полным архивом аккаунта.

## Языки

Новые английские source keys включены в en, es, fr, ru, ar, zh-CN, zh-TW, ja, ko, de, pt-BR, it, hi, tr, pl. Каталог встроен и работает offline. `elioI18n.t` форматирует UI-переменные; `onChange` обновляет chat/tool/update подписи. Диалог, код, пути, имена инструментов и внешние ошибки защищены от автоперевода. Сам перевод не требует API модели.

## Полное переименование 1.0.1

Согласованно заменены собственные имена приложения, Cargo-пакета, расширения, инструментов, протокола, хранилища, pairing-файлов и asset prefix. Канал — NeDioBrando/Elio, EXE — elio.exe, расширение — elio-Extension. Установите новый EXE и расширение вместе; автоматической миграции старых настроек и совместимости со старым протоколом не заявляется. Порт и функциональные ограничения не менялись.

Версия сохранена 1.0.1, поскольку выпуск ещё не опубликован. Имена исходных авторов и юридические уведомления не заменяются новым авторством.

Стартовая identity — `You are Elio, the user's AI assistant.`; подтверждение — `Elio is ready to assist you.`. Правила инструментов сохранены. test-elio-identity.cjs проверяет варианты промпта и стартовый обработчик; контрольная сумма подтверждает отсутствие иных правок config.js сверх механического переименования, identity и подтверждения готовности.

## Lightpanda

Native UI зависит от транспорта read/send/start/stop/pin, а не от chrome.tabs напрямую. Это сохранённая граница для будущего адаптера. Текущая реализация всё ещё использует расширение, Chromium API и DOM-провайдеры. Lightpanda не содержит автоматически chrome-extension API; адаптер и его provider-тесты предстоит реализовать отдельно.

## Проверка владельцем перед выпуском

1. Собрать через Build-Windows.ps1 на Windows x64 и запустить свежий EXE с соответствующим расширением.
2. Для ChatGPT, DeepSeek и Claude: Start → отправить два разных запроса → убедиться, что оба user/assistant сообщения видны в Elio.
3. Проверить работу при фокусе native окна, после сворачивания браузера, после смены/закрепления вкладки, после навигации нового чата.
4. Проверить Stop во время генерации и внешнего MCP, затем явное продолжение. Убедиться, что нет повторного инструмента/повтора запроса.
5. Искусственно прервать связь: черновик и статус неопределённой доставки остаются; автоматического replay нет.
6. Проверить реальные tool call/result/error и открыть их детали; обычный текст не исчезает.
7. Переключить язык в Settings; проверить popup/панель сайта/чат. Содержимое разговора не переводится.
8. Проверить масштабирование Windows и 900px минимальную ширину окна.
9. В отдельной тестовой папке проверить будущие обновления Elio с новым форматом пакета, перезагрузку расширения, возврат после ошибки и сохранность настроек. Миграция прежнего продукта автоматически не поддерживается. Не тестировать установку на единственной рабочей копии проекта.

## Светлая / тёмная тема

`core/theme.css` содержит семантические цветовые токены двух палитр; `core/theme.js` — общую SVG-кнопку, доступные подписи, применение и обработку ошибок сохранения. Кнопки: верхняя панель приложения, шапка popup и панель расширения на странице. Настройка `rsColorMode` сохраняется в native preferences / Chrome storage и включена в существующий allowlist синхронизации. Старые настройки без этого поля получают светлую тему. При ошибке сохранения кнопка возвращает предыдущую тему; ожидание ответа не позволяет polling сбросить переключение. Новые подписи включены во все 15 каталогов. CSS перекрашивает только поверхности Elio, не фон и текст сайтов ИИ.
