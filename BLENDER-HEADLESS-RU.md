# Blender без окна в Elio

В меню расширения откройте Connections → Blender → **Start / Resume headless**.
Blender 3.6+ должен быть установлен. Elio ищет его автоматически; при необходимости
укажите полный путь к `blender.exe`. Имя проекта — латинские буквы, цифры, `-`, `_`.
**Connect desktop Blender** переключает обратно на обычный Blender с MCP-addon.
Headless не требует addon и не открывает собственный редактор.

## Экономия ресурсов
- Один процесс Blender на Elio, последовательное выполнение команд.
- По умолчанию 2 вычислительных потока. Это настройка Blender, не жёсткий лимит
  потребления CPU сторонними Python-библиотеками.
- Нет постоянно работающего viewport или автоматического рендера после каждой правки.
- Через 120 секунд без команд процесс выгружается. Следующая команда открывает
  сохранённую сцену; завершённые команды не повторяются.
- Превью создаётся только по запросу: PNG, Cycles CPU, 8 samples, до 768 px.
  Это рендер сцены, а не снимок окна Blender. Сам рендер временно нагружает CPU.
- Память мешей, текстур и вычисление тяжёлой геометрии всё ещё нужны. Headless
  убирает затраты интерфейса, но не делает любую сцену дешёвой.

## Инструменты и сохранение
Существующие инструменты Blender используют выбранный backend: Python/bpy,
информация о сцене и объектах, моделирование, экспорт FBX и предпросмотр.
Используйте bpy data API и операторы без зависимости от VIEW_3D. Команды,
которым нужно окно/клик/viewport, не заменяются скрытым запуском GUI.
Существующая передача экспорта в Studio остаётся отдельным этапом Elio.

После успешной Python-команды сцена сохраняется атомарно в
`<Elio workspace>/.elio-blender/<project>/scene.blend`.
Ошибка Python восстанавливает предыдущую сохранённую сцену. Stop/тайм-аут
останавливает только принадлежащий Elio worker; для продолжения нажмите
Start / Resume headless. Сохранённые шаги остаются; текущий незавершённый шаг
не гарантирован. При закрытии Elio его worker завершается автоматически.
Блокировка проекта запрещает двум worker одновременно перезаписывать одну сцену.
Лог запуска: `worker.log` рядом с файлом сцены.

## Доступ
Управление требует существующего локального pairing Elio. Worker слушает
только loopback и проверяет случайный токен. Python работает с правами вашего
пользователя: это **не песочница ОС**. Откат сцены не отменяет запись Python
в сторонние файлы. Режим read-only / ограничения папок не обходятся.
Elio не устанавливает Blender и не меняет разрешения автоматически.

## Проверки
`node test-blender-headless.cjs` — маршрутизация расширения и переключение превью.
`python tools/test_blender_headless.py` — контракты исходников и зеркала.
Для настоящего Blender задайте `ELIO_TEST_BLENDER` (Blender executable) и
`ELIO_TEST_NATIVE` (собранный Elio). Интеграционный тест проверяет авторизацию,
один процесс, создание/сохранение/откат, PNG, FBX, idle-resume, отмену до отправки,
адресный Stop, тайм-аут и завершение worker вместе с Elio.
