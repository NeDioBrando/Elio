# SynerixCode v1

Независимый модифицированный форк PlazCode 1.24.20 для Windows 10 x64 и Chrome/Chromium. Предок проекта — ZeroScript-Free. Лицензия GPL-3.0-or-later; исходные авторские и сторонние уведомления сохранены. Это не официальный релиз PlazCode.

## Что готово

- Имя приложения и будущего EXE: `synerixcode`, `synerixcode.exe`.
- Новая синяя палитра по умолчанию и собственный значок.
- Полная версия приложения и расширения — **1.0.0**, синхронизирована с Cargo и manifest.
- Перенесён Vani-провайдер из предоставленного тестового расширения. Добавлены HTTPS `vani.ai`, `www.vani.ai`, `c.vani.ai`; сам чат открывается на **https://c.vani.ai/c**. На главной странице сайта без чата выполнить команды нельзя.
- Прежний обновлятор PlazCode заменён собственным каналом GitHub Releases **NeDioBrando/SynerixCode**. В приложении, на странице ИИ и в popup есть единый статус **Outdated** и кнопка **Обновить**; установка — только по нажатию. См. UPDATES-RU.md.
- Убраны рекламные/донатные предложения прежнего издателя, чтобы они не выдавались за поддержку synerixcode.
- Остальные провайдеры и инструменты сохранены. Установка внешних MCP-зависимостей не является обновлением synerixcode и остаётся доступной.

## Важно: состав этой поставки

**Этот исходный архив не содержит готового Windows EXE.** В нём исходники, готовое распаковываемое расширение, тесты и воспроизводимый сценарий сборки EXE. Не подставляйте вместо него прежний PlazCode.exe: в старом бинарнике останется обновлятор!

Linux-проверка Rust и тесты не доказывают работоспособность Windows GUI. После сборки необходима проверка на вашем Windows 10 с Roblox Studio. См. UPDATES-TEST-REPORT.md и исторический TEST-REPORT.md.

## Вариант A — получить EXE через GitHub Actions

Локально устанавливать Rust/Visual Studio в этом варианте не нужно.

1. Создайте собственный пустой GitHub-репозиторий. Учитывайте условия бесплатного/платного запуска Actions для своего аккаунта.
2. Загрузите **содержимое** папки исходников в корень репозитория, включая скрытую папку `.github`. Файлы `agent/Cargo.toml` и `.github/workflows/build-windows.yml` должны лежать именно по этим путям. Не загружайте ZIP одним файлом.
3. Откройте **Actions → Build and release SynerixCode (Windows x64) → Run workflow**.
4. Только после зелёного завершения скачайте artifact `synerixcode-Windows-x64`. Внутри будет `synerixcode-v1.0.0-Windows-x64.zip` с новым EXE, DLL и расширением.
5. Если сборка красная, сохраните лог неудачного шага. Готовым считается только успешно собранный архив; workflow в этой среде не запускался.

Если используете Git в терминале (адрес репозитория подставьте свой):

```powershell
git init -b main
git add .
git commit -m "synerixcode v1"
git remote add origin <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
git push -u origin main
```

Публикация и запуск Actions не выполнялись автоматически от вашего имени. При распространении EXE предоставляйте получателям соответствующий исходный код и лицензионные уведомления в соответствии с GPL.

## Вариант B — собрать локально на Windows 10 x64

Понадобятся:

- Visual Studio 2022 Build Tools: **Desktop development with C++**, MSVC x64/x86 и Windows 10/11 SDK с `rc.exe`.
- Rust **1.99.1**, target `x86_64-pc-windows-msvc` (GNU toolchain для этого build.rs не подходит).
- Python 3.13 и Node.js 24, доступные как `python`, `node`, `cargo` в терминале.
- Интернет для первоначального получения Cargo-зависимостей.

В PowerShell из папки исходников:

```powershell
rustup toolchain install 1.99.1 --profile minimal
rustup override set 1.99.1
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Windows.ps1
```

Сценарий запускает аудит форка, Rust-тесты, Windows-тесты помощника обновления и JS-тесты, `cargo build --release --locked`, затем проверяет `synerixcode.exe --version` и формирует:

```text
dist\synerixcode-v1.0.0-Windows-x64.zip
```

В EXE будут встроены новое имя, версия и ICO. Рядом упаковывается неизменённый Microsoft `WebView2Loader.dll` из upstream Windows-релиза; см. WINDOWS-RUNTIME-NOTICE.txt / windows-runtime/NOTICE.txt. Сам WebView2 Runtime должен быть установлен из официального источника Microsoft. Ничего не отключайте в защите Windows; неподписанный EXE может вызывать предупреждение о неизвестном издателе.

## Установка готовой Windows-сборки

1. Полностью закройте старый PlazCode и его обновлятор, если они запущены. Не кладите synerixcode в старую папку PlazCode: внешний старый обновлятор способен перезаписать её независимо от нового кода.
2. Распакуйте ZIP в отдельную папку, например `C:\synerixcode`. Не запускайте EXE прямо из ZIP.
3. Отключите старое расширение PlazCode, чтобы два расширения не добавляли две панели на один сайт.
4. В Chrome откройте `chrome://extensions`, включите **Режим разработчика → Загрузить распакованное расширение** и выберите `synerixcode-Extension`. В Edge/Brave/другом Chromium используйте его страницу расширений. Тестировался Chromium; каждый другой браузер отдельно не проверялся.
5. Запустите `synerixcode.exe`, откройте Roblox Studio и подключите Studio привычным для исходного проекта способом. Настройка стороннего MCP-рантайма может потребовать Python/Node и разрешений на первоначальную установку зависимостей.
6. Откройте `https://c.vani.ai/c`, перезагрузите вкладку и нажмите Start Agent в панели synerixcode.

Расширение загружается распакованным из `synerixcode-Extension` внутри установленной папки; в manifest нет `update_url`. Наш обновлятор заменяет эту папку вместе с приложением, после чего расширение нужно перезагрузить кнопкой панели и обновить вкладки ИИ. Расширение, загруженное из другой папки, автоматически не заменяется. Общие обновления Chrome, Roblox Studio, WebView2 и внешних инструментов этот форк не отключает.

## Проверка после Windows-сборки

- Заголовок/панель показывают `synerixcode v1.0.0`; при наличии более нового релиза появляется Outdated и кнопка Обновить. Ошибка проверки не равна актуальной версии.
- Через 10 минут простоя и повторный запуск папка/версия не меняются.
- На Vani видна одна панель; Start Agent получает список команд.
- Сначала выполните только чтение, например запрос имени открытого place или доступных сервисов; затем при необходимости проверьте изменение на отдельном тестовом place.
- Stop останавливает цикл; другое поддерживаемое AI-приложение по-прежнему подключается.
- Не запускайте PlazCode параллельно: используется тот же локальный порт моста `127.0.0.1:3000`. Новая айдентика не означает автоматическую совместную работу двух мостов на одном порту.

У synerixcode отдельные имена путей/ключей приложения. Автоматическая миграция старой памяти, настроек и секретов не добавлялась; при необходимости используйте штатный экспорт/импорт, не копируйте токены в переписку.

## Ограничения проверки Vani

В живом анонимном чате проверены поиск поля ввода, одна отправка, подтверждение отправки, распознавание пользовательского/AI-сообщения и чтение завершённого ответа. Передача изображений, авторизованные аккаунты, исчерпание квоты, все модели, продолжительные диалоги и выполнение команд в Windows Roblox Studio здесь не проверялись. Если сайт меняет DOM, адаптер может потребовать корректировки. При неопределённом результате отправки адаптер не отправляет сообщение повторно сам.

```powershell
node test-synerixcode.cjs

```

Канонические файлы расширения лежат в корне (`core`, `providers`, `manifest.json` и т. д.); при изменении их необходимо синхронизировать с `synerixcode-Extension`. Аудит сравнивает обе копии. Код Vani: `providers/vani.js`. Список изменений: FORK-CHANGES.md. Выпуск версий: `python tools/set_version.py X.Y.Z`, коммит, новый тег `vX.Y.Z`; Windows workflow собирает ZIP и публикует релиз. Подробности и обязательная Windows-проверка: UPDATES-RU.md.
