# Elio 1.0.1

Тёплый интерфейс со светлой и тёмной темами для работы с браузерным ИИ и инструментами Roblox Studio / AgentScript / Blender. Это независимый GPL-3.0-or-later форк. Исходное авторство и сторонние уведомления сохранены в UPSTREAM-SOURCE.txt, BRANDING-NOTICE.txt и файлах лицензий.

## Что изменилось

- Новый бренд Elio и предоставленная владельцем иконка. Светлые поверхности, графитовый текст, бежевые акценты; без неоновых тем и рекламного оформления.
- Чат — начальный экран. Ответы ИИ слева, человеческие сообщения справа; композер закреплён снизу, история занимает доступную ширину.
- Служебные инструкции и результаты инструментов свёрнуты в раскрываемые карточки. Исходный текст сохранён, а не удалён. Успех показывается по фазе выполнения или реальному результату, не просто по факту появления JSON.
- Новые строки чата и обновлятора включены в 15 языков существующей системы. Сообщения, код, имена инструментов и ошибки внешних сервисов не переводятся автоматически.
- Исправлена логика подтверждения отправки, чтения истории, повторной отправки и явного продолжения после Stop. Подробности: [ELIO-RU.md](ELIO-RU.md).

## Важно: это исходники, а не готовый EXE

Этот архив **не содержит собранного Windows EXE**. Не запускайте старый EXE из прежнего архива: HTML нового чата и стили встраиваются при компиляции Rust. Linux-тесты не заменяют проверку Windows GUI, реальных аккаунтов ИИ и Roblox Studio.

Архив исходников плоский: `agent`, `core`, `desktop`, `elio-Extension`, `.github` должны оказаться **непосредственно в корне** репозитория. Не создавайте внутри него вторую вложенную копию проекта. Не загружайте исходный ZIP в Releases вместо установочного пакета.

## Получить Windows EXE через GitHub Actions

1. Сохраните свои пользовательские данные отдельно. В GitHub Desktop откройте Repository → Show in Explorer. Уберите старые файлы проекта из рабочей папки, но **сохраните `.git`**. Распакуйте содержимое нового архива прямо в корень репозитория, включая `.github`, без дополнительной вложенной папки. Это важно: простое копирование поверх не удалит старые переименованные каталоги. Выполните Commit to main → Push origin.
2. Откройте **Actions → Build and release Elio (Windows x64) → Run workflow** на обновлённой ветке `main`.
3. Дождитесь зелёного завершения. Скачайте artifact **Elio-Windows-x64**. Внутри него — установочный ZIP `elio-v1.0.1-Windows-x64.zip`.
4. Распакуйте установочный ZIP. В папке `elio` запускайте **elio.exe** — в пакете один основной EXE.
5. В `chrome://extensions` обновите путь распакованного расширения на **elio-Extension** из этого же пакета и перезагрузите расширение. Затем обновите вкладки ИИ.
6. Откройте поддерживаемый чат в браузере, выберите вкладку в Elio, подключите агента. Если открыто несколько чатов — закрепите нужный.

WebView2 Runtime должен быть установлен в Windows. MCP-серверы и Roblox Studio настраиваются как прежде. Vani открывается по https://c.vani.ai/c, а не на главной странице сайта.

## Локальная сборка Windows x64

Установите Node.js 24, Python 3.13, Rust (MSVC toolchain), Visual Studio Build Tools с Desktop development with C++ и WebView2 Runtime. Из корня проекта выполните:

```powershell
.\Build-Windows.ps1
```

Сценарий проверяет аудит, регрессии, Windows updater helper, запускает Rust-тесты, компилирует свежий EXE и создаёт ZIP в `dist`. При ошибке сборки старый бинарник не подставляется.

## Публикация автообновления

Версия оставлена **1.0.1**: эта сборка ещё не опубликована. Не перезаписывайте ранее опубликованные теги и ZIP.

После загрузки исходников и успешной тестовой сборки создайте тег **v1.0.1** на нужном коммите. Workflow соберёт ZIP, загрузит его и опубликует стабильный GitHub Release. Название релиза можно менять: обновлятор проверяет **тег**, версии пакетов и точное имя asset, а не заголовок.

Канал обновлений: **`NeDioBrando/Elio`**. Новые имена: asset `elio-v1.0.1-Windows-x64.zip`, корень пакета `elio/`, приложение `elio.exe`, расширение `elio-Extension`. Старые идентификаторы протокола и хранилища тоже заменены: устанавливайте приложение и расширение из одного пакета. Перенос старых настроек и pairing-файлов автоматически не выполняется. Для следующей версии синхронно повысьте Cargo, оба manifest и тег.

Установка запускается по кнопке, не автоматически без согласия. Проверка SHA-256 и HTTPS доверяет вашему GitHub-каналу; это не независимая цифровая подпись. См. [UPDATES-RU.md](UPDATES-RU.md).

## Проверки и ограничения

Фактически выполненные проверки описаны в [ELIO-TEST-REPORT.md](ELIO-TEST-REPORT.md). Реальные Windows EXE / WebView2, live-чаты, отмена внешнего инструмента и установка поверх старой версии требуют отдельного прогона на Windows.

Lightpanda пока не реализована и не заявляется совместимой: интерфейс работает через отдельный транспорт, но Chromium-адаптер и DOM-провайдеры всё ещё необходимы.

### Переключение темы

Кнопка луны/солнца находится рядом с колокольчиком в приложении, в шапке окна расширения и на его панели на странице ИИ. Светлая тема — мягкий льняной фон без ярко-белых поверхностей; тёмная — тёплый угольный фон с бежевыми акцентами. Выбор сохраняется в `rsColorMode` и передаётся через существующую синхронизацию настроек. Сама страница ChatGPT/Claude/другого провайдера не перекрашивается. При первом запуске без сохранённого выбора используется светлая тема.

Архив `Elio-v1.0.1-full-source.zip` заменяет предыдущий архив исходников 1.0.1. Версия оставлена прежней, поскольку сборка ещё не опубликована. После замены исходников пересоберите EXE и перезагрузите расширение.

## Новый адрес репозитория

Основной репозиторий: https://github.com/NeDioBrando/Elio. GitHub API и проверка точного URL Windows-архива теперь используют этот адрес. Новый бинарник не зависит от перенаправления прежнего адреса. На автоматическое обновление старых бинарников после переименования не полагайтесь: при необходимости установите первую новую сборку вручную.

В GitHub Desktop: Repository → Show in Explorer; в локальной папке уберите прежние исходники и распакуйте содержимое этого архива прямо в корень, не удаляя `.git`; проверьте Changes → Commit to main → Push origin. Затем на сайте Actions → Build and release Elio (Windows x64) → Run workflow. Готовый артефакт — Elio-Windows-x64. ZIP исходников не является готовой Windows-сборкой.

Внутренние названия теперь тоже Elio: Cargo-пакет `elio-agent`, бинарник `elio`, инструменты, протокол, хранилище и пути обновлятора. Старое расширение не смешивайте с новым приложением; загрузите новое `elio-Extension` и выполните подключение заново. Авторские и лицензионные уведомления исходного проекта сохранены — это единственное намеренное исключение из переименования старого бренда.

## Identity стартового промпта

Модель получает короткую строку `You are Elio, the user's AI assistant.`. После обнаружения инструментов ожидается точный ответ **`Elio is ready to assist you.`**. Правила вызова инструментов, ограничения, формат команд и остальное поведение промпта не переписывались.

Старые release-tools/package-appearance.py и publisher-appearance.py отключены с понятным сообщением: используйте Build-Windows.ps1 и текущий workflow, а не исторический pipeline публикации.
