How memory and saved chats work

Memory notes are short titled notes the AI saves about a project, such as which script handles a system or a decision that was made. Each note has a title so it can be found and reviewed later. Notes can be added, edited or removed above.

Saved chat logs keep captured messages for review or download. A continuation file carries recent task context into a new chat.

Notes describe past decisions; the AI still checks current scripts before editing. Neither notes nor chat logs are a game backup.

Execution

Control where the AI works, when a task pauses, and what happens when Stop is pressed. These settings are shared with the browser extension. Command and time limit changes apply to the next task or when resuming a paused task.

Roblox Studio edits the open Roblox game through its bridge. AgentScript works with files and commands in the connected project folder. Engine changes apply only to the selected AI tab, not other tabs or browsers.

Message size

Limits are enabled by default and can be changed or switched off. Large tool results are kept in full and delivered in readable pages. The AI can read every page without running the command again. These settings cannot increase an AI website's own limits or set its native answer length.

Commands per run: the maximum number of AI tool commands before synerixcode pauses, only when Pause at run limits is enabled. Limits are off by default. For example, 20 allows 20 counted commands. Use 0 for no command limit. Internal helper calls do not count.

Minutes per run: elapsed time allowed for one run. When the time is reached, synerixcode pauses before starting the next command; it does not undo work or interrupt the current command. Use 0 for no time limit.

Seconds between commands: waits this long before each command result is sent back to the AI. Raise it (for example to 5) if DeepSeek or another site says you are sending too fast. 0 keeps the normal speed.

Offer to continue previous chat: when on (the default), opening a new chat asks whether to continue where your previous chat left off or start a new project. Turn it off to always start fresh without that prompt. This does not delete saved chats, memory or continuation files.

Automatic visual review: after a visible Studio change, synerixcode can send a screenshot back to an AI that supports images so it can check the result. At most three images are sent per run, at least 30 seconds apart. This is a visual check, not a guarantee that the game works.

Save continuation file: downloads a small JSON handoff with the active request, recent chat excerpts and unfinished queued requests. It is not a whole-chat export or a Roblox game backup. To use it, open a fresh supported AI chat, open synerixcode Memory, import it with Load into selected chat, review the context, then ask the AI to continue.

Resume paused task: continues a task paused by its command or time limit and starts a fresh allowance using the current limits. It does not start a new task when nothing is paused.

Immediate: stop AI generation and stop waiting for tools right away; cancel helper processes that synerixcode owns where possible. Safe: stop AI generation and new commands, then let the current command finish. Neither option undoes edits already made, and some external tools cannot be cancelled.

Sandbox: AgentScript stays inside the connected project folder. Ask: request approval for writes and command execution. Full: allow AgentScript to work outside the project folder and run PC commands. Roblox actions still use the connected Studio bridge.
