# Elio 1.0.1 — исправления чата и темы

Основа: `NeDioBrando/Elio`, коммит `b58627aa99f9eed64378bbe4e6607917844ba5f4`.
Версия продукта и расширения остаётся **1.0.1**. Это исходники, не готовый Windows EXE.

## Что исправлено

- Чтение истории из приложения теперь явно сбрасывает кеш списка сообщений провайдера. Новые строки Notion и потоковые изменения видны без перезагрузки страницы, в том числе при чтении из скрытой вкладки браузера. Таймер фонового экспорта/MutationObserver больше не является единственным условием свежести снимка.
- Ответ `chat-read` передаёт актуальное состояние работы даже с `not_modified`: подключение, генерация, выполнение конкретного инструмента, работа, остановка или простой.
- Над полем ввода появился анимированный знак E: его язычок тянется к точке. Надпись «Elio is thinking…» переливается нейтральным серым градиентом. Надписи локализованы на 15 языков; при reduced motion анимация отключается. При простое или ошибке чтения индикатор не выдаёт видимость работы.
- Исправлен статус у поля ввода: он не показывает «Готово» одновременно с полученным от браузера состоянием генерации. При известной текущей работе отправка недоступна.
- Служебные стартовые запросы, включая обычный текст подключения Notion и маркерные сообщения, скрыты в представлении нативного чата. Исходная история не удаляется и не переписывается; результаты инструментов остаются отдельными карточками. Простое упоминание стартового текста в обычном сообщении не скрывается.
- Стабильные DOM-строки не переподключаются на каждом обновлении. При возврате фокуса выполняется чтение; зависшее чтение ограничено сроком, ошибки автоматически повторяются только для чтения. Отправка сообщений автоматически не повторяется, существующие request ID, черновики, ACK и проверки целевого чата сохранены.
- Убраны старые синие/фиолетовые цвета в CSS расширения, Ultra, дополнительных панелях, динамических стилях и закрытом редакторе. Переменные старой палитры не перекрывают палитру Elio. Страница самого AI-сервиса не перекрашивается; семантические зелёные/красные/янтарные состояния остаются.
- Тёмная тема используется при первом запуске и при отсутствующем/некорректном значении настройки. Явно сохранённая светлая тема остаётся светлой.
- Корневая и вложенная копии расширения синхронизированы.

Промпты, identity и точная фраза `Elio is ready to assist you.` не изменены.
Предыдущие исправления тестов LF/CRLF и путей Windows сохранены.

## Проверки

- Сборочные Node-проверки identity/rename/audit/chat/theme/updates и новый `test-elio-chat-live.cjs`.
- Новый `test-elio-notion-live.cjs`: настоящий код провайдера Notion и экспорт истории на DOM-фикстуре; воспроизводится устаревший кеш, затем проверяются новая строка, потоковое изменение и скрытая вкладка без reload/MutationObserver.
- Chromium: настоящий HTML и JS приложения с HTTP-заглушкой; потоковые обновления, скрытый setup, состояние работы при неизменной ревизии, ошибка чтения и восстановление, отправка, черновики, повтор с тем же ID, переключение чатов, 390 px, reduced motion.
- Chromium: настоящий popup со заглушкой Chrome API; первый запуск в тёмной теме, сохранение светлой, расширенные настройки и Ultra. Для overlay проверяются настоящий шаблон и динамически добавляемые CSS панелей, отсутствие синих цветов и отсутствие перекрашивания сайта.
- Нативный интерфейс: обе темы, 10 разделов, локализация, сохранение/откат темы, раскрытие карточек инструментов.
- Контракт упаковщика Windows проверен на фикстурах, включая канонические и алиасные пути.
- Rust: **132 пройденных теста, 0 ошибок, 1 игнорируемый тест**.
- Дополнительно пройдены регрессионные DOM-тесты Notion: block transcript, turn keys, tool status, send flow, startup/fast startup, protocol retry, results.

Проверки с DOM/HTTP/Chrome-заглушками не заменяют проверку на реальной авторизованной странице Notion/ChatGPT и в Roblox Studio. Windows EXE и .NET updater helper в этой Linux-среде не собирались/не запускались; для них требуется новый запуск GitHub Actions.

## Как поставить через GitHub Desktop

1. Открыть текущий репозиторий через **Repository → Show in Explorer**.
2. Распаковать содержимое этого архива прямо в его папку, согласиться на замену файлов. Не удалять скрытую папку `.git`; в архиве её нет. `Build-Windows.ps1` должен оказаться в корне, без лишнего вложенного каталога.
3. В GitHub Desktop заполнить **Summary**, затем **Commit to main → Push origin**.
4. На GitHub открыть **Actions → Build and release Elio (Windows x64) → Run workflow**. Нужен новый запуск с новым коммитом, не повтор старого failed run.
5. После сборки использовать новый EXE и обновлённую папку расширения. Один раз перезагрузить расширение, открытые вкладки AI и приложение для загрузки нового кода. После этого для появления каждого нового сообщения обновлять страницу не требуется.

Если раньше уже была сохранена светлая тема, нажать луну один раз: новый default намеренно не стирает сохранённый выбор.
