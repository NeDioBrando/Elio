# elio v1 — проверка

Дата: 2026-10-18. База: исходный архив Elio 1.24.20 из GitHub Releases; Vani: предоставленный пользователем ZIP 1.24.13-notion-vani.

## Проверено в Linux

- `cargo check --manifest-path agent/Cargo.toml`: успешно.
- `cargo test --locked --manifest-path agent/Cargo.toml`: **126 тестов пройдено, 0 ошибок, 1 тест пропущен** (3 библиотечных + 123 нативного приложения).
- Синтаксис 69 JavaScript/встроенных HTML script-блоков: без ошибок.
- Исходные regression-наборы parser, ChatGPT, Claude, skills, animation: успешно. Все остальные upstream-наборы целиком не запускались.
- `node test-elio-audit.cjs`: успешно. Проверяет бренд/версию, существование manifest-ресурсов, Vani-регистрацию без дублирующего провайдера, API-контракт адаптера, отсутствие updater entrypoints/опроса, идентичность исходной и упакованной копий расширения, синтаксис runtime JS.

## Локальный предпросмотр интерфейса

- Desktop home/settings при 1440×1000 и popup при ширине 390 px отрендерены в Chromium и визуально проверены.
- В мокированном API-предпросмотре нет JS-ошибок, fatal-сообщений или запросов обновлений; версия — v1. Это проверка HTML/JS с mock API, а не Windows WebView2.

## Живой Vani

Страница: https://c.vani.ai/c, анонимная сессия Chromium.

- Адаптер обнаружил TEXTAREA, readiness=true, login gate=false.
- Отправлено одно нейтральное тестовое сообщение; поле очистилось, появилось 1 пользовательское сообщение и началась генерация.
- Прочитан завершённый ответ `ELIO_TEST_OK`.
- Корректно определены роли двух сообщений `data-turn-id=pub-1/pub-2`; генерация завершилась, scanError=null.
- Никакие MCP-команды или команды Roblox Studio в живом чате не исполнялись.

## Не проверено

- Сборка MSVC/Windows SDK, запуск EXE/GUI и трея на Windows 10.
- GitHub Actions workflow (подготовлен, но не опубликован и не запускался).
- Полный цикл Vani → расширение → EXE → Roblox Studio.
- Вход в аккаунт, изображения, квоты, все модели Vani, долгие сессии, каждый Chromium-браузер отдельно.

Итог: исходники и расширение прошли перечисленные проверки. Это не утверждение о полностью протестированном Windows-релизе; готового EXE в исходном архиве нет.
