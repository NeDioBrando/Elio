# Desktop Chat — результаты проверки

Дата: 2026-10-18. Исходная версия: `158359b52a80549f6325ec55b40dc28e0a239674`.
Среда: Linux, Node 24, локальный headless Chromium / Playwright, Rust stable.

## Пройдено

- `cargo check --locked --manifest-path agent/Cargo.toml`: успешно, включая изменённые Rust-обработчики и встраивание UI. Существующие предупреждения компилятора не устранялись.
- `cargo test --locked --manifest-path agent/Cargo.toml`: **126 passed, 0 failed, 1 ignored** (3 библиотечных и 123 теста приложения). Это Linux-тесты; Windows-only участки не исполнялись.
- `node test-elio-audit.cjs`: аудит продукта/manifest, синтаксис 65 runtime-скриптов, отсутствие updater и синхронность копий расширения.
- `node test-desktop-chat.cjs`: исполнение новых веток реальных функций в VM с тестовыми зависимостями; обновление ответа по ревизии, not_modified, ограничения размера, защита назначения, стабильный request ID, закрепление/снятие закрепления и синхронность исходников.
- `node test-desktop-chat-ui.cjs`: реальный HTML desktop с встроенными общими модулями и новым чатом, подставной HTTP-транспорт. Проверены старт страницы, пустое состояние, история, изменение текста без дублирования сообщения, инертный HTML/JS из ответа, pin, принятие запроса, сохранение черновика при 504, ручной повтор с прежним ID, раздельные черновики разных чатов и отсутствие автоматической переотправки. Нет pageerror.
- Локальные снимки состояний empty/ready/error при 1460×900 и компактного контейнера при 390×844 просмотрены. На узком контейнере проверялся модуль чата с тестовым скрытием native sidebar/titlebar; минимальная ширина настоящего окна приложения остаётся 900 px.
- `node test-parser.js`: все сценарии пройдены.
- `test-provider-preservation.js`: проверены **1028** исходных тел функций провайдеров. Тест ожидает acorn по жёстко заданному пути release-tools/node_modules; использована подстановка этого импорта на предустановленный acorn, без изменения теста или runtime провайдеров. Прямой запуск до подстановки не работал из-за отсутствия dependency по указанному пути.
- `git diff --check`: нет ошибок пробелов/формата.

## Не проверено

- Сборка и запуск Windows exe, Windows SDK/MSVC, WebView2 и tray на Windows.
- Сквозной живой запрос через аккаунт пользователя → сайт ИИ → расширение → Roblox Studio/Blender.
- Все провайдеры и их текущие DOM в живых аккаунтах. Используется существующий RSProvider-контракт; конкретный сайт может потребовать адаптации.
- Lightpanda и будущий альтернативный браузерный адаптер.
- Работа в режиме сна компьютера/при остановленном браузере, вход, CAPTCHA и ограничения сайтов.

Макетные проверки не подменяют живую проверку. Принятие задания расширением не является гарантией доставки сайту или исполнения команды в Studio.
