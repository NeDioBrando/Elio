# Elio 1.0.1 — перенос рекомендаций из PlazCode 1.24.21–1.24.25

Это **полный исходный проект**, а не патч и не готовый Windows EXE. Собирайте через ваш обычный GitHub Actions / Build-Windows.ps1. Версия продукта остаётся 1.0.1. Приложение и расширение нужно брать из одной сборки.

## Что перенесено

### Меньше лишнего текста в чате
- По умолчанию — короткая инструкция запуска. Полные инструкции доступны по запросу через `elio_help`; полный старт можно вернуть в настройках расширения (`Full startup instructions`).
- Память, справка и дополнительные рекомендации занимают только оставшееся место сообщения. Они не вытесняют результат команды.
- Большой результат сохраняется целиком и читается страницами через `elio_result_read`. Ограничение длины сообщения не означает потерю исходного результата.
- Повторяющиеся Ultra-инструкции ограничены, выдержки шаблонов по умолчанию — до 8000 символов.
- Для служебных отправок DeepSeek введён минимум 5 секунд. Это не гарантия отсутствия ограничений аккаунта; предупреждение говорит об этом прямо.

### Скриншоты и совместимость
- Скриншоты показываются через canvas, а не внешний `img`: это работает и на страницах, где политика безопасности запрещает такие картинки. Сохранены увеличение, Escape, копирование и освобождение ресурсов.
- У сборки теперь собственный идентификатор и версия протокола. Если приложение видит активное расширение другой сборки, появляется отдельное предупреждение — не путать с наличием нового релиза.
- Сведения об активной сборке расширения живут 120 секунд. Совсем старое расширение, которое ещё не отправляет свой идентификатор, этим способом надёжно определить нельзя.

### Защита и история
В **Home → Task history → Safety** добавлены:
- «Только чтение» — блокирует изменения проекта и исполнение непрозрачного кода; по умолчанию выключено.
- Подтверждение удаления и непрозрачного кода — по умолчанию включено. Luau, shell и внешние addon-вызовы тоже требуют подтверждения: Elio не пытается угадать, удаляет ли произвольный код данные.
- Разрешённые локальные папки. При непустом списке непрозрачные shell/desktop/addon-команды блокируются, поскольку проверить их реальные цели заранее нельзя. Workspace-wide glob/grep-поиск в этом режиме также блокируется: используйте list_directory/tree/read_file с явным разрешённым путём.

После блокировки откройте Safety, обновите состояние, прочитайте команду и разрешите её один раз. Затем агенту нужно повторить **ту же** команду в течение двух минут. Нажатие разрешения ничего само не запускает. Смена аргументов требует нового подтверждения. Сохранение политики сбрасывает ожидающие разрешения.

Политика хранится в `%LOCALAPPDATA%\elio\safety.json`. Существующие journal/checkpoint/Undo используются повторно, а не заменяются второй системой отката. Откат возможен только для поддерживаемых, проверенных изменений; непрозрачный код и сторонние плагины не превращаются в гарантированно отменяемые операции.

Это ограничение инструментов Elio, **не системная песочница** и не защита от произвольной программы на вашем ПК. Подтверждения стоят на центральном пути команд агента и legacy-кода; интерактивные пользовательские API Explorer/Toolkit/Blender/Figma дополнительно проверяют режим чтения, но не являются общей системой подтверждения каждого клика. Внешняя гонка с заменой файлов/ссылок не исключается как в полноценном OS sandbox.

### Память: сохраняем Elio, добавляем полезное
Старая память не заменяется upstream-хранилищем. Сохранены проектные области, исходники заметок, история, revision/etag и защита от устаревших правок.

Добавлено:
- **Review memory** — список непроверенных записей, отсутствующих источников/свидетельств, давних проверок и изменённых зависимостей.
- **Record verification** — фиксация нового свидетельства проверки с контролем версии заметки. Это запись предоставленного человеком/агентом свидетельства, **не независимое доказательство истины**.
- Зависимости заметки от файла или Studio-пути и его отпечатка. Для поддерживаемых записанных изменений через checkpoint зависимые заметки помечаются `stale`. `audit` также сравнивает явно переданные свежие отпечатки.
- Устаревшие заметки исключаются из автоматически подобранного контекста, включая переходы по связям. Самих заметок это не удаляет.
- Локальные reference images: PNG/JPEG/WebP загружаются через интерфейс, уменьшаются и нормализуются в PNG; есть ограничения размера/количества, изоляция проектов и очистка метаданных. Просмотр не загружает внешние URL. Повторные нажатия не плодят canvas, таймаут декодирования освобождает поздний bitmap.
- Изображения не отправляются провайдеру автоматически. Явный вызов агентом `elio_vault image_read` прикладывает выбранное изображение к следующему сообщению для провайдера, поддерживающего изображения. После этого оно, разумеется, становится доступно этому провайдеру.
- Граф: переключаемая сетка, выделение соседей, перетаскивание узлов. Без бесконечного анимационного цикла.
- **Obsidian snapshot**: новая отдельная папка с Markdown, разрешёнными wikilinks и локальными картинками. Экспорт не открывает Obsidian сам и не перезаписывает пользовательские правки предыдущего экспорта.

**Обратной автоматической синхронизации с Obsidian нет.** Snapshot — переносимый снимок, а не второй рабочий backend. Правки вне Elio и эффекты произвольного Luau не отслеживаются все до единого: для них нужны свежая проверка/отпечатки и аудит. При выключенной автоматической памяти агент не сохраняет/не подтверждает записи; ручные действия пользователя остаются доступны.

## Что проверить у себя после сборки
1. Обновить приложение **и** расширение, перезагрузить вкладки ИИ. Проверить, что нет предупреждения о разных сборках.
2. Обычный диалог, запуск агента, большой результат и его чтение страницами; для DeepSeek — паузу служебной отправки.
3. На вашем провайдере: скриншот, увеличение/Escape, копирование и вложение картинки.
4. На тестовом проекте: режим чтения, однократное разрешение Luau/удаления, история и поддерживаемый Undo.
5. В своей памяти: Review, отметку stale, новое свидетельство проверки, reference image, граф и Obsidian snapshot. Перед обновлением полезно сохранить собственную резервную копию данных.
6. Реальные Eclipse / VFX Studio / QP2, Figma и Blender: их регрессионные проверки здесь выполнены на доступных фикстурах, а не в ваших установленных программах.

## Что действительно проверено
См. `UPSTREAM-21-25-TEST-RESULTS.json`. Нативные тесты и изолированное приложение проверены на Linux; интерфейс — в настоящем Chromium с временным профилем. GitHub Windows Actions, Windows GUI, ваш аккаунт провайдера и живой Roblox Studio в этой среде не запускались. Отсутствие найденных ошибок не означает гарантии отсутствия всех багов/утечек.

## Основа переноса и лицензии
Исследованы релизные материалы и читаемый JavaScript версий 1.24.21–25. Новый нативный upstream-код этих релизов в исследованном публичном дереве не был доступен: соответствующие функции реализованы в исходниках Elio, а не скопированы из неизвестного EXE. Из существующей реализации Elio не удалены Figma, Oriveo, Eclipse, VFX Studio, QP2 и memory backend.
